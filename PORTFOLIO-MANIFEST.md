# Home SOC Portfolio Package

This repository is the sanitized public-facing version of the Home SOC / SIEM project.

Included:

- Project README and architecture
- Detection engineering documentation
- Controlled incident reports
- Recovery documentation
- Stability validation documentation
- Final QA documentation
- Sanitized Wazuh custom rules
- Portfolio screenshots
- Backup validation evidence

Intentionally excluded:

- Live Docker Compose configuration
- Environment files
- Passwords and API credentials
- Private keys and certificates
- Wazuh Agent keys
- Internal user databases
- Backup archives
- Dashboard export files
- Live runtime data

This repository is separate from the production HomeLab Wazuh deployment.
